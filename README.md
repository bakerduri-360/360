# 360dgree — موقع تعريفي (Landing Page)

موقع تعريفي أحادي الصفحة (Single Page) لشركة **360dgree** المتخصصة في:
- 🎥 كاميرات المراقبة (CCTV Surveillance)
- 🌐 البنية التحتية للشبكات (Network Infrastructure)
- 🏠 المنزل الذكي (Smart Home)

الموقع **ثنائي اللغة بالكامل** (عربي / إنجليزي) مع تبديل فوري بين اللغتين ودعم كامل لاتجاه الكتابة من اليمين لليسار (RTL) عند اختيار العربية، دون الحاجة لإعادة تحميل الصفحة.

---

## 🖼️ لمحة عامة

الموقع مبني بتقنيات ويب أساسية فقط (HTML / CSS / JavaScript) بدون أي مكتبات أو أطر عمل خارجية (Frameworks)، مما يجعله:
- خفيفًا وسريع التحميل
- سهل الفهم والتعديل حتى للمبتدئين
- قابلاً للاستضافة مجانًا على GitHub Pages أو أي استضافة ثابتة (Static Hosting)

### الأقسام الرئيسية
1. **Header / Navbar** — شريط تنقل ثابت (Sticky) مع شعار متحرك ومبدّل اللغة
2. **Hero** — قسم ترحيبي رئيسي مع إحصائيات وأزرار دعوة لاتخاذ إجراء (CTA)
3. **About** — نبذة عن الشركة وأقسامها الثلاثة
4. **Services** — بطاقات تفصيلية للخدمات الثلاث
5. **Process** — آلية العمل على 4 خطوات (معاينة، تصميم، تركيب، دعم)
6. **Contact** — معلومات التواصل + نموذج طلب عرض سعر
7. **Footer** — روابط سريعة وحقوق النشر

## ✨ المزايا التقنية

- **ثنائية اللغة (i18n) بدون مكتبات:** يعتمد `main.js` على كائن JavaScript بسيط يحتوي كل النصوص بالعربية والإنجليزية، ويتم استبدال محتوى العناصر التي تحمل السمة `data-i18n` عند الضغط على زر اللغة.
- **RTL تلقائي:** عند اختيار العربية يتغيّر `dir` الخاص بالصفحة إلى `rtl` تلقائيًا وتتبدل كل التخطيطات (المسافات، المحاذاة، الأسهم...) لتناسب الاتجاه.
- **خطوط مخصصة لكل لغة:** تُستخدم خطوط Google Fonts التالية:
  - `Space Grotesk` و `IBM Plex Sans` و `IBM Plex Mono` للإنجليزية
  - `IBM Plex Sans Arabic` للعربية
- **تصميم متجاوب (Responsive):** يعمل على الجوال، التابلت، وسطح المكتب عبر `@media queries`.
- **نموذج تواصل بسيط:** النموذج حاليًا يعمل من جهة العميل (Client-side) فقط، أي أنه *لا يرسل البيانات فعليًا إلى بريد إلكتروني أو خادم*. راجع قسم "ربط النموذج بخدمة حقيقية" أدناه لتفعيله.

## 🚀 طريقة التشغيل محليًا

لا يحتاج المشروع لأي تثبيت أو أدوات بناء (Build Tools). يكفي:

1. حمّل أو استنسخ (Clone) المشروع
2. افتح ملف `index.html` مباشرة في المتصفح

أو، إذا أردت تشغيله عبر خادم محلي بسيط (مستحسن لتفادي بعض القيود المتعلقة بالمتصفحات):

```bash

python3 -m http.server 8000

# ثم افتح المتصفح على
http://localhost:8000
```

## ✏️ تعديل النصوص أو إضافة لغة جديدة

كل النصوص القابلة للترجمة موجودة في بداية ملف `js/main.js` داخل كائن `translations`:

```js
const translations = {
  en: { hero_h1_a: "Every angle of your property,", ... },
  ar: { hero_h1_a: "كل زاوية في عقارك،", ... }
};
```

- لتعديل نص موجود: غيّر القيمة المقابلة للمفتاح (key) باللغة المطلوبة.
- لإضافة عنصر نصي جديد في الصفحة:
  1. أضف السمة `data-i18n="مفتاح_جديد"` على عنصر HTML في `index.html`
  2. أضف نفس المفتاح `مفتاح_جديد` بقيمتين (عربي/إنجليزي) داخل `translations` في `main.js`

## 📬 ربط نموذج التواصل بخدمة حقيقية

حاليًا دالة `handleSubmit()` في `main.js` تكتفي بعرض رسالة "تم الإرسال" شكليًا. لجعل النموذج يرسل البيانات فعليًا، لديك خياران شائعان وسهلان بدون الحاجة لخادم خاص بك:

**الخيار 1: Formspree (مجاني لعدد محدود من الطلبات)**
1. أنشئ حسابًا على [formspree.io](https://formspree.io)
2. أنشئ نموذجًا جديدًا واحصل على رابط الإرسال (Endpoint)
3. في `index.html` أضف `action` و `method` على وسم `<form>`:
   ```html
   <form action="https://formspree.io/f/xxxxxxx" method="POST">
   ```
4. احذف أو عدّل `onsubmit="return handleSubmit(event)"` حسب رغبتك

**الخيار 2: EmailJS** — يرسل النموذج بريدًا إلكترونيًا مباشرة من الواجهة الأمامية دون خادم، عبر مكتبة JavaScript يتم تضمينها في الصفحة.
